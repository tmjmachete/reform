Admin Onboarding

Testing the re:form School Admin Panel

Work through each section in order. By the end you will have created, written, and published a lesson — and tested the student-facing features yourself.

01

Confirm your admin access

Before anything else, make sure you can reach the admin panel and that your account has the correct role.

1
Go to reformpod.vercel.app/school and sign in with your Google account if you are not already signed in.
2
Navigate to /school/admin. You should see the Courses list. If you see a "Not authorised" page, ask Theo to set your profile role to admin in the Users panel.
3
Confirm that the sidebar shows links for Courses, Sessions, Requests, Users, Comments and Community.
✓
What you should seeA list of existing courses. If it is empty, that is fine — you will create content in the next step.
02

Create a test lesson

Create a new lesson inside an existing course, or ask Theo which course to use as a sandbox.

1
From the admin panel, click any course title to open its detail page.
2
Scroll to the Add lesson form at the bottom. Enter a Title (e.g. Test Lesson) and a Slug (e.g. test-lesson — lowercase, hyphens only). Leave sort order as-is.
3
Click Add lesson. You will be redirected to the lesson editor page automatically.
✓
What you should seeThe lesson editor with fields for Title, Slug, YouTube link, Study notes, Duration, Sort order, and a Published checkbox.
03

Write notes with the rich text editor

The Study notes field is now a full editor — no HTML required. Try each feature below.

1
Click inside the Study notes editor area and type a paragraph of text.
2
Select some of your text and click B in the toolbar to make it bold. Click I for italic. Both buttons should highlight when active.
3
Press Enter twice and click H2 to start a new heading. Type a heading title. Notice it renders larger.
4
Press Enter again and click •— to start a bullet list. Type 2–3 items, pressing Enter between each.
5
Click Insert image in the toolbar. Pick any image from your computer. Wait a moment — the image should upload to Supabase Storage and appear inline in the editor.
6
Click Save lesson at the bottom of the form.
✓
What you should see after savingThe page reloads and your formatted content is still there. The image appears full-width, rounded, with a subtle border.
!
Image size limitFiles must be under 10 MB. JPEG, PNG, and WebP are all accepted.
04

Publish the lesson

Lessons are hidden from students until you toggle Published. This lets you draft and review before anything goes live.

1
In the lesson editor, scroll down to the Published checkbox and tick it.
2
Click Save lesson.
3
Open a new browser tab and go to /school/courses/[course-slug]/test-lesson — substituting the actual course slug. You should see the lesson exactly as a student would.
4
Scroll down and click Mark complete to test the progress button. The button should change to Completed ✓.
✓
What you should seeYour formatted notes, the image, and the Next/Previous navigation if other lessons exist in the course.
05

Comment as a student

Students can discuss lessons in the comments section at the bottom of each lesson page. Test the full flow here.

1
On the published lesson page, scroll past the notes to the Discussion section.
2
Type a comment in the text box and click Post. It should appear immediately below with your name and avatar.
3
Click Reply on your own comment and post a reply. The reply should appear nested under the parent comment.
4
In the admin panel, go to /school/admin/comments and confirm your test comment appears there. You can hide or delete it from that page.
✓
What you should seeComments appear instantly, with threaded replies. The admin comments page shows them with moderation controls.
06

Request a live session

Students can request live Q&A sessions. Test both the student-facing request form and the admin review queue.

1
Go to /school/sessions — the student-facing sessions page. Click Request a session.
2
Fill in the request form: choose a course, describe your topic, and submit.
3
Switch to the admin panel and go to /school/admin/requests. Your request should be listed with status Pending.
4
Click Approve or Decline on the request. Optionally, add an admin note and save it.
5
(Optional) Create a scheduled session at /school/admin/sessions — set a title, date, and a Zoom or Google Meet link. Publish it and confirm it appears on /school/sessions.
✓
What you should seeThe request moves from Pending to Approved/Declined in the admin requests view. Approved sessions with a join link show a button on the student sessions page.
07

Final checklist

Tick each item as you complete it. All green means you are ready to publish real lessons.
